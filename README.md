# 🧠 MedVoice AI – Intelligent Medical Voice Assistant

![Status](https://img.shields.io/badge/Status-Active%20Development-orange)
![Python](https://img.shields.io/badge/Python-3.x-blue)
![License](https://img.shields.io/badge/License-MIT-green)

> ⚠️ This project is currently under active development.
> Features are being built, tested, and improved continuously.

An AI-powered voice assistant designed for the healthcare domain
that enables users to interact using natural speech and receive
accurate, understandable medical insights.

Built with a focus on **accessibility, real-time interaction,
and patient-friendly explanations**, especially for rural and
semi-urban users.

## 🚀 Features

### 🎙️ Voice-Based Interaction
- Real-time speech-to-text and text-to-speech communication
- Natural conversational experience

### 🧑‍⚕️ Medical Query Handling
- Symptom-based suggestions
- Basic disease information
- General healthcare guidance

### 🌍 Multi-language Support
- Supports regional languages for better accessibility

### 🤖 AI-Powered Understanding
- NLP-based intent recognition
- Context-aware responses

### 📊 Patient-Friendly Explanations
- Simplifies complex medical terms into easy language

### 🔒 Secure & Private
- No sensitive data stored without consent
- Designed with healthcare privacy in mind

## 🛠️ Tech Stack

| Category | Technologies |
|----------|-------------|
| Backend | Python, FastAPI, SQLAlchemy |

## ⚙️ How It Works

1. 🎤 User speaks through microphone
2. 📝 Speech converted to text (STT)
3. 🧠 AI processes query using NLP
4. ⚙️ Backend generates medical response
5. 🔊 Response converted to voice (TTS)
6. 👂 User hears the answer

## 🚀 Getting Started

- Python 3.x

```bash

cd Ai-Voice-Agent
pip install -r requirements.txt
python main.py
```
